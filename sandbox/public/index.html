Redoma Links Experimental GitHub

Short links, kept in 1,296 small databases.

Paste a long address and get a short one. This is an experimental project of Redoma, a TypeScript template for Cloudflare Workers and Linux.

    How it works

    1. A code is drawn Six random letters and digits, like k3x9ab. There is no counter to wait for.
    2. Two characters pick the database k3 means the link is kept in links-k3. A database is created the first time it is needed.
    3. One query opens the link A visit asks that one small database, however many links exist in the others.

    Redoma Links is the example app of Redoma. The whole server is one short file.

    It is an experiment: links may stop working at any time, and anyone who has a short link can open it. Do not shorten anything private.
